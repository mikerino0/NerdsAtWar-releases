# Nerds at War spelen

Nerds at War is een realtime strategiespel uit de napoleontische tijd. Je stuurt regimenten over een kaart en verslaat de tegenstander. De game is nog in ontwikkeling: er gaan dingen mis, en dat is precies waarom jouw feedback nodig is.

Op dit moment speel je tegen de AI. Tegen elkaar spelen komt eraan. Je hebt Windows nodig.

## Installeren

1. Download `NerdsAtWar.exe` van de [downloadpagina](https://github.com/mikerino0/NerdsAtWar-releases/releases/latest).
2. Start het. De game komt op je bureaublad en in het Startmenu te staan als **Nerds at War**. De eerste keer wordt ook de game opgehaald, dat is ongeveer 115 MB.
3. Daarna mag de download weg.

Waarschijnlijk zegt Windows eerst "Windows heeft uw pc beschermd". Dat komt doordat de game niet digitaal is ondertekend. Klik op **Meer info** en daarna op **Toch uitvoeren**. Dat hoeft maar één keer.

## Updates

Start het spel altijd met **Nerds at War** op je bureaublad of in het Startmenu. Dat kijkt elke keer of er een nieuwe versie is, haalt die op en start de game. Je hoeft er zelf niets voor te doen. Zonder internet start gewoon de versie die je al hebt.

## Besturing

- **Selecteren:** linkermuisknop, of sleep een kader.
- **Orders geven:** rechtermuisknop. Slepen bepaalt de opstelling, op een vijand klikken is aanvallen.
- **Camera:** beweeg de muis naar de rand van het scherm, en zoom met het scrollwiel.
- **Alle toetsen:** druk op F1 in het spel.

## Feedback geven

Vertel vooral wat raar voelde, wanneer de AI iets doms deed, en wat je leuk vond. Noem daarbij het versienummer, dat linksonder in het hoofdmenu staat.

Ging er iets echt mis? Open dan in het hoofdmenu **Settings** en klik op **Open log folder**. Stuur het bestand `godot.log` mee, daar staat ook in op welke kaart je speelde. Doe dat voordat je de game opnieuw start, want anders wordt dat bestand overschreven.
